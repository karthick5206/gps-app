### btree_gist on production (Lead action before deploy)

`20261116090100_planned_trip_origin` runs `CREATE EXTENSION IF NOT EXISTS btree_gist;` (doc 15 §8.2). On production
PostgreSQL 18.6 the extension is available (1.8) but not installed, and the migration role cannot create it. Install
it once as superuser **before** `prisma migrate deploy`:

```
sudo -u postgres psql -d veetracer -c 'CREATE EXTENSION IF NOT EXISTS btree_gist;'
```

The migration statement is then a no-op. Without this step the migration fails and is rolled back (no conditional
block on purpose: every environment gets the same integrity rules). Owner decision O16 governs the path.
