## 3. Behaviour changes for v1.8 planned trips

- ETMS trips through `/api/planned-trips`: no path, no stop / event coordinates, personal stops named `Stop n` (ROUTE trips unchanged). `PlannedTripStopDto.lat/lng` and `PlannedTripEventDto.lat/lng` are now nullable (web handles it).
- Creating, generating or editing a ROUTE trip onto a vehicle / driver held by an active ETMS run → 409 `VEHICLE_BUSY` / `DRIVER_BUSY` (generator: logged, occurrence skipped).
- Tracker alert texts for ETMS non-place stops say `Stop n`.
- `RoutingService.routeVia` concurrency cap applies to route saves / previews too.
